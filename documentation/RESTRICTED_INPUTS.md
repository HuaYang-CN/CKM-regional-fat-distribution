# Restricted input not distributed

The header-only CSVs under documentation/schemas contain no participant rows. They describe candidate column names, not complete clinical records. The retained final implementation is authoritative: derivation requires group, seven fat variables, Sex, Smoke and Alcohol_Use; Age is used in sensitivity analyses. Repeated observations require ID, time, group and the seven fat variables, with one baseline and one follow-up row per person. group is the final adjudicated binary contrast (0 = Stages 0-2, 1 = Stages 3-4); historical CKM_stage fields do not replace it. Coding and additional display variables are checked in the retained scripts. The optional measurement_date schema header is a field description, not a participant date.

Chinese upstream age-eligibility/cohort-construction implementation was not retained. These scripts start from filtered workbooks and cannot reconstruct that upstream selection. Do not fabricate example records. Authorized users must obtain the appropriate deidentified inputs and preserve original column names and coding.
